Privacy Policy

JustWavs Uploader · last updated October 27, 2026

JustWavs Uploader ("the app") is a private tool that the creator of the YouTube channel JustWavs uses to upload and schedule that channel's own videos. Only the channel's owner signs in to it.

YouTube API Services

The app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is covered by the Google Privacy Policy.

What the app accesses

  • An OAuth sign-in token for the Google account that owns the JustWavs channel.
  • The channel's ID, title and playlists.
  • The channel's own videos: their titles, descriptions, tags, privacy status, scheduled publish time, processing status and country restrictions.

It doesn't access any other channel, anyone else's account, comments, subscribers, messages or analytics.

How the data is used

Only to upload the channel's finished videos, set their details, thumbnails, captions and playlists, schedule them, and check that they went public. Nothing is used for advertising, profiling or any other purpose.

Where it is stored

The sign-in token is stored only on the channel owner's own computer, in a file only that user account can read. Video IDs and schedule times are kept in the channel's private production files on the same computer. The app has no server and keeps no copies anywhere else.

Sharing

The app shares no data with anyone. It doesn't sell data, use third-party analytics or show ads.

Revoking access and deleting data

Access can be revoked at any time from your Google Account's third-party access page, or at security.google.com/settings/security/permissions. Revoking it stops all access at once. Deleting the token file on the owner's computer removes the app's stored credentials; to have any stored data deleted, email the contact below and it will be removed within 7 days.

Changes

If this policy changes, this page will be updated and the date at the top changed.
